# Expense_System
Expense_System คือ ระบบจัดการค่าใช้จ่าย (Expense Management System) ที่ใช้สำหรับ บันทึก ติดตาม และสรุปค่าใช้จ่าย ภายในองค์กร หน่วยงาน หรือใช้ส่วนตัว เพื่อให้รู้ว่า เงินถูกใช้ไปกับอะไร เท่าไร และเมื่อไร 💰
🔎 แนวคิดของระบบ Expense_System

ระบบนี้ถูกสร้างขึ้นเพื่อช่วยให้การจัดการค่าใช้จ่ายเป็นระเบียบ และสามารถตรวจสอบย้อนหลังได้ง่าย แทนการใช้กระดาษหรือ Excel แบบกระจัดกระจาย
ตัวอย่างการใช้งาน เช่น
-ค่าใช้จ่ายสำนักงาน
-ค่าเดินทางราชการ
-ค่าอุปกรณ์ / เวชภัณฑ์
-ค่าใช้จ่ายโครงการต่าง ๆ

⚙️ โครงสร้างหลักของระบบ

1️⃣ ระบบผู้ใช้งาน (User Management)

ใช้สำหรับจัดการผู้ใช้งานระบบ เช่น
-Admin → จัดการข้อมูลทั้งหมด
-User → บันทึกค่าใช้จ่าย
-Approver → อนุมัติค่าใช้จ่าย

ตัวอย่างข้อมูล
-ชื่อผู้ใช้
-Username / Password
-สิทธิ์การใช้งาน

2️⃣ ระบบบันทึกค่าใช้จ่าย (Expense Recording)

ผู้ใช้สามารถบันทึกข้อมูลค่าใช้จ่าย เช่น
-วันที่ใช้จ่าย
-รายการค่าใช้จ่าย
-หมวดหมู่ค่าใช้จ่าย
-จำนวนเงิน
-ผู้บันทึก
-แนบเอกสาร (ใบเสร็จ)

ตัวอย่าง
วันที่	รายการ	หมวดหมู่	จำนวนเงิน
01/03/2026	ซื้อกระดาษ A4	วัสดุสำนักงาน	350
02/03/2026	ค่าน้ำมันรถ	เดินทาง	1,200

3️⃣ ระบบหมวดหมู่ค่าใช้จ่าย (Category Management)
เพื่อจัดกลุ่มค่าใช้จ่ายให้ดูง่าย เช่น
-ค่าวัสดุสำนักงาน
-ค่าเดินทาง
-ค่าอาหาร
-ค่าซ่อมบำรุง
-ค่าเวชภัณฑ์

ช่วยให้ รายงานสรุปค่าใช้จ่ายได้ชัดเจน

4️⃣ ระบบอนุมัติค่าใช้จ่าย (Approval System)
-บางองค์กรต้องมีขั้นตอนอนุมัติ เช่น
-ผู้ใช้บันทึกค่าใช้จ่าย
-หัวหน้างานตรวจสอบ
-ผู้บริหารอนุมัติ

สถานะอาจมี เช่น
-Pending
-Approved
-Rejected

5️⃣ ระบบรายงาน (Reports)
ระบบสามารถสรุปข้อมูล เช่น
-รายงานค่าใช้จ่ายรายวัน
-รายงานรายเดือน
-รายงานตามหมวดหมู่
-รายงานตามผู้ใช้

ตัวอย่างรายงาน
เดือน	ค่าใช้จ่าย
มกราคม	25,000
กุมภาพันธ์	18,500
มีนาคม	31,200

6️⃣ ระบบ Dashboard 📊
แสดงภาพรวมค่าใช้จ่าย เช่น
-ค่าใช้จ่ายทั้งหมด
-ค่าใช้จ่ายเดือนนี้
-หมวดหมู่ที่ใช้เงินมากที่สุด
-กราฟรายเดือน

ทำให้ผู้บริหารเห็นภาพรวมได้ทันที
💻 เทคโนโลยีที่นิยมใช้สร้างระบบ
เช่น
-PHP + MySQL
-Bootstrap (ทำ UI)
-Chart.js (กราฟ Dashboard)
-JavaScript / jQuery
